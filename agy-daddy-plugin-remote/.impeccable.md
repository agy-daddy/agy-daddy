## Design Context

### Users
Developers monitoring, steering, and approving AI coding sessions remotely from a phone (commuting, away from desk, or multi-tasking). They operate one-handed in portrait viewports (360px–430px wide) under variable network quality (LAN, Tailscale, Cloudflare Tunnel) and need instant clarity, zero mis-taps, and desktop-grade telemetry/control parity without desktop sidebar clutter.

### Brand Personality
Precision, calm, tactile. Like a pocket field-monitor paired with an editorial notebook: quiet neutral surfaces, high-legibility typography, crisp tabular telemetry, and responsive 1:1 physical gestures that follow the thumb without bounce or theatrical chrome.

### Aesthetic Direction
- **Visual Tone**: Minimalist mobile console aligned with the Agy-Daddy Web workbench family (`monochrome` default plus `purple`, `blue`, `green`, `amber`, `red` across `auto`/`dark`/`light`), adapted for touch density and outdoor/indoor contrast.
- **Stream Hierarchy**: De-carded editorial assistant prose (no outer card boxes or `#seq` headers) paired with compact right-aligned user bubbles, scannable inline `+/-` diff previews, and single-line bottom status strips that never occlude the conversation or composer.
- **Anti-References**: Nested bordered cards-inside-cards, cramped `< 44px` desktop icon buttons, bouncy/overshooting spring animations, full-page white-screen channel reloads, and stacked `position: fixed` floating banners blocking the thumb typing zone.

### Design Principles
1. **Thumb-First Geometry (`>= 44x44px`)**: Every interactive control—including compact icon pills, drawer actions, and sheet headers—must expose at least a `44x44px` hit target (via box sizing or non-overlapping `::after` expansion) with safe inter-target spacing, and fit `360px` width with zero horizontal overflow.
2. **1:1 Direct Manipulation + Explicit Fallbacks**: Edge drawers, bottom sheets, and drill-down pickers track finger `touchmove` 1:1 via GPU-composited `translate3d` CSS custom properties without React/Preact re-render jank, paired with visible edge/drag handles and `44x44px` button fallbacks.
3. **Token-Pure Surfaces (Gate 4 Strict)**: Define every color token exclusively in `web/src/styles/tokens.css`. Component `.module.css`, `global.css`, and `.tsx` files must contain zero hardcoded `#hex` literals and zero forbidden legacy palette values.
4. **Calm Exponential Motion**: Animate only `transform` and `opacity` using exponential ease-out curves (`cubic-bezier(0.22, 1, 0.36, 1)` / `cubic-bezier(0.16, 1, 0.3, 1)`), honoring `DrawerSpeed` (`120/200/320/0ms`) and `prefers-reduced-motion: reduce`.
5. **Accessible Mobile Ergonomics**: Never lock viewport pinch-zoom (`no maximum-scale=1`), keep form inputs `>= 16px` to prevent iOS Safari focus auto-zoom, maintain WCAG AA contrast in both light and dark modes, and preserve offline queue + approval reliability.
