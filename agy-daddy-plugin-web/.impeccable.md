# Design Context — Agy-Daddy PC Web Workbench

- **Target Audience**: Developers and technical leads monitoring and steering multiple parallel Antigravity AI coding agents from a desktop browser.
- **Core Use Cases**:
  1. Immediately locate active, running, or unread projects and sessions without wading through dozens of inactive repos.
  2. Read long, structured AI responses (headings, code, tables, lists) and inspect conversational turns at a glance.
  3. Review file modifications & diffs quickly, and steer agents with slash commands and model selection.
- **Brand Personality & Tone**: Refined monochrome-first editorial workbench — calm neutral surfaces, crisp hairline separation, generous breathing room for prose, semantic color reserved strictly for live running/unread states and +/- diffs, zero glowing purple/cyan AI slop.
- **Layout Principle**: Conversation-first spatial budget (~53%+ center reading column on 1440px, compact ~268px sidebar, ~28% workspace dock), progressive disclosure for intermediate thinking/tool noise and raw JSON payloads, and non-overlapping floating navigation.
